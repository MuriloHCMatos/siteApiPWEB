# 💱 Conversor de Moedas - API PWEB

Aplicação web interativa para conversão de moedas em tempo real, desenvolvida para a disciplina de **Programação Web (PWEB)**.

---

## 🛠️ Tecnologias Utilizadas

* **Framework:** [Vue.js 3](https://vuejs.org/) (Composition API)
* **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Ícones:** [Lucide Vue Next](https://lucide.dev/)

---

## 📋 Pré-requisitos

Antes de iniciar, certifique-se de ter o **Node.js (versão 18 ou superior)** e o **npm** instalados em sua máquina.

---

## 🚀 Como Executar o Projeto

1. **Clone o repositório:**

```bash
git clone https://github.com/SEU_USUARIO/siteApiPWEB.git
```

2. **Acesse o diretório do projeto:**

```bash
cd siteApiPWEB/siteApiPWEB
```

3. **Instale as dependências:**

```bash
npm install
```

4. **Execute a aplicação em modo de desenvolvimento:**

```bash
npm run dev
```

5. **Acesse no navegador:**

Abra o endereço indicado no terminal, geralmente:

```text
http://localhost:5173/
```
